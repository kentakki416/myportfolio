職務要約

新卒で株式会社サイバーエージェントに入社し、アバターSNSアプリ「Pigg Party」のバックエンド開発からSREまで一貫して担当。VIP・アバター整形・フリマなど主要機能の要件定義から実装・テストまでをリードするとともに、SRE業務ではDatadog整備やログの整理によるオブザビリティの強化や、レイテンシ5倍改善、HelmによるWeb課金基盤構築、TerraformによるIaC導入、年間3,000万円以上のコスト削減など、開発・運用の両軸でプロダクトを支えてきました。

並行して副業でも複数社のSRE業務に従事し、10億レコード規模のDBマイグレーション、CDKによるIaC刷新、ECS移行、Datadog / Sentry等のオブザビリティ基盤構築を担当。2026年3月からは株式会社wevnalに参画し、Bxプラットフォームのインフラ刷新と監視基盤強化に取り組んでいます。

フルスタック開発（Next.js / React Native / Node.js / Go）に加え、SRE・インフラ（AWS / GCP / Kubernetes / Terraform）を横断できる点と、要件定義からリリース・運用改善まで一貫して推進できる点が強みです。

個人開発・OSSプロジェクト

Money Management（家計管理アプリ）

概要: Turborepo によるモノレポ構成で、Web（Next.js）と管理画面の2つのフロントエンドを持つ家計管理アプリ。複数決済サービスの CSV を取り込み、支出を自動カテゴリ分類・可視化。

  • 銀行・決済サービス別 CSV インポート（SMBC / MUFG / PayPay 等）
  • キーワードマッチによる支出の自動カテゴリ分類
  • 月別 / カテゴリ別ダッシュボード
  • Google OAuth + JWT 認証
  • 管理画面によるユーザー / カテゴリルール管理

技術スタック: Next.js / TypeScript / Tailwind CSS / Node.js / MySQL / Terraform / GitHub Actions

設計上の工夫: DI パターンによる Controller / Repository / Service の責務分離、Zod スキーマをモノレポパッケージとしてフロントと共有し API 境界を型安全化。

GitHub: https://github.com/kentakki416/money-management

SNS Battle（リアルタイム1対1ビデオマッチング）FEATURED

概要: Turborepo + pnpm モノレポで Web（Next.js 16）/ Admin / Mobile（Expo）/ API（Express 5）/ マッチング Worker を一括管理する、LiveKit ベースの 1対1 ビデオマッチング SNS。1万人規模の同時待機を想定した設計。

  • LiveKit による 1対1 ビデオマッチング（10ラウンド / テーマ自動切替 / 紙吹雪演出）
  • LiveKit Data Channel を用いたリアクション・スタンプの即時相互反映
  • カウントダウン / テーマ切替などの SFX 同期再生
  • MBTI 相性スコアに基づくトークテーマの事前スケジューリング
  • グラスモーフィズム UI（Tailwind v4 + Framer Motion）

技術スタック: TypeScript / Next.js 16 / Express 5 / BullMQ / LiveKit / PostgreSQL / Redis / Expo / Vercel / AWS ECS Fargate / Terraform / GitHub Actions（OIDC）

設計上の工夫:

  • API と マッチング Worker を分離し、LiveKit Room 発行・テーマ進行・Webhook 副作用処理をキュー駆動で非同期化
  • WebSocket ではなく SSE + LiveKit Data Channel に寄せ、ALB の idle timeout チューニングのみで運用可能に
  • packages/schema（Zod）で API 境界を完全型付け
  • Web は Vercel、API / DB / Redis / Worker は AWS というハイブリッド構成
  • ALB の Blue / Green を Terraform module 化し、ECS タスク差し替え時の無停止リリースを担保
  • GitHub Environments + Required Reviewers で本番反映前の手動承認ゲートを構築

Programming Practice（プログラミング学習プラットフォーム）

概要: Turborepo によるモノレポ構成で、Web（Next.js 16）/ Mobile（Expo）/ API（Express 5）を一括管理。ブラウザ上で JavaScript の問題を解き、自動採点で即フィードバックを得られる学習プラットフォーム。

  • Web エディタによる JavaScript 問題演習・コード実行・テスト採点
  • Web Worker サンドボックスによるブラウザ完結の自動採点（DoS / インジェクションリスクなし）
  • 問題コンテンツ（meta.json / description.md / initial-code.js / tests.json）を Git 管理の静的ファイルとして提供
  • Google OAuth + JWT による認証・解答状況の蓄積
  • Go / C++ 追加に向けたサーバー側サンドボックス採点方式を設計

技術スタック: Next.js 16 / TypeScript / Tailwind CSS / Express 5 / PostgreSQL 16 / Redis 7 / AWS ECS Fargate / Terraform / GitHub Actions

設計上の工夫: Web Worker による隔離実行で console.log を差し替えて stdout を捕捉し、AsyncFunction で assertion を評価することでサーバー負荷ゼロの安全な採点を実現。問題本体を静的ファイル化し、DB スキーマと教材バージョン管理を分離。

GitHub: https://github.com/kentakki416/programming-practice
